# 玩家说明（第一版草稿）

> 面向玩家的说明：操作键、存档、已知限制。构建与开发记录见 `README.md` 和 `docs/` 里的其他文件。
> 这份是草稿：标“待实机”的地方我没能亲手玩过，发布前请你核对一遍。

## 一、操作（电脑）

| 键 | 作用 |
|---|---|
| 方向键 | 移动 / 选择（原作不用 WASD） |
| C、回车、空格 | 确认 |
| X、Esc | 取消；在地图上打开暂停菜单 |
| Z、W、Y、Shift | 按住奔跑；战斗里是 Mega 进化 / 快速捕捉 |
| A、Q、Page Up | 向前翻页（L） |
| S、Page Down | 向后翻页（R） |
| F、F5、Tab | 地图上：快捷菜单（登记的道具和可用的秘传招式）；战斗指令菜单：战场信息；招式菜单：招式详情；队伍里：寄存系统 |
| Ctrl | 跟随宝可梦开 / 关 |
| M | 有城镇地图道具时打开地区地图；Ctrl+M 显示 / 隐藏小地图；= / - 调小地图尺寸，Ctrl+= / Ctrl+- 调缩放（地区地图上按 Z 进“小地图设置”） |
| Alt | 游戏加速（1×→2×→3×→4× 循环），Ctrl+Alt 回到 1×；右上角显示倍率 |
| F11 | 全屏 / 窗口 |
| F6 / F9 | 开发者快速存档 / 快速读档（不在存档列表里） |

## 二、操作（安卓，待实机）

只有屏幕按键，点屏幕本身不响应：左下方向键，右下 C / X / Z / 加速，左右肩键 L / R。
地图上的 R 键等于电脑的 F5（快捷菜单），战斗里的 R 键是战场信息 / 招式详情。

## 三、存档

- 暂停菜单 → 保存：8 个存档位（存档1…存档8）。
- **自动存档**：每走 200 步自动存到“自动保存”位（地图 1、119、426 不计步）。和原插件一样，**至少手动存过一次档之后**自动存档才会生效。读档界面里自动保存排在最前面；默认选中最新的存档，而自动保存的时间总是比上一次手动存档早一秒，所以默认选中的是手动存档，向左 / 右切换才能看到自动保存。
- 存档文件在 `用户目录\.pokemon-runtime\saves\`（电脑）；安卓在应用自己的目录里。
- 旧版本的存档能读；新增的内容（分布图鉴、登记的道具、天气）读旧档时自动补上。

## 四、这一版里有的新功能

- **任务日志**（暂停菜单 → 任务）。
- **分布图鉴**（暂停菜单 → 分布图鉴；地区地图上按 F5 / R 看当前格子的分布）。去过的区域才会列出，每种遇敌方式（草丛、冲浪、钓鱼……）一格，抓全后盖章。
- **快捷菜单**：背包里选“登录”可以把有现场用途的道具（自行车、钓竿、喷雾、逃脱绳、城镇地图……）登记，在地图上按 F5 / R 直接使用；队伍里会的秘传招式也在这里。
- **天气**：下雨、暴风雨、下雪、暴风雪、沙暴会有画面；换地图时按各地图的设定自动开始 / 结束。
- **钓鱼**：面朝水面，背包里用钓竿。
- **战场信息 / 招式详情**：战斗里按 F5。

## 五、已知限制（第一版）

- **旧版存档转移**暂时关闭：NPC 会说“对不起，由于引擎更新，宝可梦传送已经暂时关闭”。
- **邮件**（给宝可梦带邮件 / 写邮件 / 邮箱）没有做；邮件类道具可以买，但不能写信。
- **小地图**默认关闭，要有“城镇地图”道具才会显示；与原插件一样，只有一个区域里有放置坐标的地图才能显示位置。
- **神秘礼物**没有服务器，固定回复找不到礼物。
- 天气里的雨天变暗、暴风雨闪光：原插件把它们画在一个空的视口上，所以原作里本来就看不到，这里同样不画。
- 冰面滑行没有做（这个游戏的地图里没有冰面）。
- 战斗里 Transform / Illusion 没有专门的音效。
- 未做的小游戏界面：Triple Triad 对战、拼图、虫赛、随机迷宫、流浪宝可梦、宝可雷达、手机/宝可装置、点唱机、暗影宝可梦（没有事件会用到）。

## 六、遇到问题

崩溃日志在 `用户目录\pokemon-runtime-crash.log`（电脑）。反馈时附上它和当时的存档文件。
