## 二、本次检查中顺手修的

## 三、缺口（按对第一版的影响排序）

### A. 玩家一定会碰到，建议第一版前做

1. **任务系统的界面与提示**（插件 282–284，约 2330 行）。事件里 `activateQuest` 119 次、`advanceQuestToStage` 167 次、`completeQuest` 118 次，状态已经在记（`QuestLog`），但：没有“接受到了新的任务！请点开任务日志查看详情！”这类提示，暂停菜单没有“任务”入口（`menuQuests` 图标已在素材里），任务名称/阶段文字（284_004 的 1683 行）没有转。玩家会被告知去看任务日志，但没有日志。
2. **钓鱼**：地图 38 事件 17 送 `SUPERROD`，使用没有任何效果（`ItemHandlers` 没有鱼竿，也没有钓鱼遇敌 `pbFishing`）。
3. **其余已送出的关键道具使用无效**：`TOWNMAP`（地图 3 送，应打开地区地图）、`LANTERN`（地图 88）、`INFINITEROPE`（地图 88，带确认的逃脱绳）、`EONFLUTE`（地图 156）、`ETHEREALNEXUS`（地图 94）。使用时会提示“这里不能使用”。
4. **旧版存档转移** `transportPokemon("0vej")`（地图 93，转移旧版/零维存档，读 `save/GameOld.rxdata` 的 Ruby Marshal 存档）：Java 没有。现在选这一项等于没反应。要么做，要么在第一版里把这两个选项去掉（改地图 93 的事件）。
5. **自动存档**（`378_001_MSF_AutoSave`）：每 200 步自动存到当前存档位（禁用地图 1、119、426）。没有做；没有自动存档时玩家只能手动存。

### B. 画面/体验，第一版可以带着发布，但最好登记给玩家

6. **天气渲染**：21 张地图的元数据带天气、事件里 7 次“设置天气”、17 次 `$game_screen.weather`。状态在记，地图上没有雨/雪/沙暴的画面（路线图 10.1）。
7. **小地图**（ES MiniMap，335–338）：默认关闭（`show_miniMap=1`），需要地图道具，选项里有一整页“小地图设置”。没有做；选项页里也没有这一页。
8. **快捷菜单与登记道具**（`221_PScreen_ReadyMenu`，F5 呼出）：背包里没有“登记”，F5 现在是别的功能。自行车等仍可从背包用。
9. **邮件**（`193_PItem_Mail`）：地图 103、110 的商店/奖励里有邮件类道具，没有写邮件/带邮件的界面。
10. **神秘礼物**：固定回复“找不到ID为0的无主神秘礼物。”（没有服务器，合理）。

### C. 没有事件会用到，不做也不影响第一版（已登记）

Triple Triad 对战界面（`pbTriadDuel`、`TriadScene`）、`pbTriadList`、`pbGiveTriadCard`、`234_PMinigame_Duel`、拼图、虫赛、随机迷宫、流浪宝可梦、宝可雷达、手机/宝可装置、点唱机、暗影宝可梦。

## 四、发布工程

| 项 | 现状 | 建议 |
|---|---|---|
| 版本号 | `builder-config.json` 与构建报告都是 0.1.0 | 定第一版版本号，写更新说明 |
| README | 仍是构建工具的开发进度记录 | 另写一份面向玩家的说明（操作键、存档位置、已知问题） |
| 存档版本 | `SAVE_VERSION = 2`，之后加的字段都是可选的，旧存档能读 | 发布前改成明确的版本号并保留迁移测试 |
| 体积 | `dist/Windows` 约 787 MB（BGM 539 MB） | 看是否要压缩/裁剪 |
| 全流程构建 | `build-pc` 全流程需要你在本机跑（Gradle 在沙箱里起不来） | 发布前在干净目录跑一遍，确认 `tools\ffmpeg` 一并带上、测试全过 |
| 缺失素材 | 25 个被地图引用的图片/行走图在源工程里本来就没有（如 `Characters/784`、`标头…` 系列图片） | 原作同样缺；可视情况补或删引用 |
| 战斗代码里的“登记”注释 | 有一部分已经过时（场地、动画播放器等现在都有了） | 发布后清理，别当成真缺口 |
